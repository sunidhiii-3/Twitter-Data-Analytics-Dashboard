# 📊 Twitter Data Analytics Dashboard (Power BI)

An interactive **Twitter Analytics Dashboard** developed using **Microsoft Power BI** to analyze tweet engagement, user interactions, and content performance through dynamic visualizations and DAX-based calculations.

This project was completed as part of the **Data Analytics Internship** at **ElevanceSkills**.

---

## 📌 Project Overview

This dashboard provides insights into Twitter engagement by analyzing user interactions, media performance, engagement trends, and top-performing tweets. It demonstrates data cleaning, transformation, filtering, DAX calculations, and dashboard development using Microsoft Power BI.

---

## 🎯 Objectives

- Analyze tweet engagement metrics.
- Compare engagement for tweets with and without app opens.
- Identify weekly media interaction patterns.
- Compare replies, retweets, and likes.
- Track monthly engagement trends.
- Identify the Top 10 highest-performing tweets.

# 📈 Dashboard Tasks

This project consists of six Power BI dashboards covering click interactions, engagement analysis, media interactions, tweet comparison, monthly engagement trends, and top-performing tweets. Detailed screenshots and explanations are available in the attached project report (Tweet Data Analytics Dashboard PDF).

## ✅ Task 1 – Click Interaction Analysis

- Compared URL clicks, User Profile clicks, and Hashtag clicks.
- Applied advanced filtering based on:
  - Interaction availability
  - Even tweet dates
  - Word Count > 40
  - Visibility between 3 PM – 5 PM IST

---

## ✅ Task 2 – App Opens vs Engagement

Compared average engagement rate of tweets:

- With App Opens
- Without App Opens

Applied filters:

- Business Hours (Weekdays)
- Even Impressions
- Odd Dates
- Character Count > 30
- Excluded tweets containing "D"
- Time visibility conditions

---

## ✅ Task 3 – Weekly Media Interaction

Visualized:

- Media Views
- Media Engagements

Applied filters:

- Last Quarter
- Even Impressions
- Odd Dates
- Character Count > 30
- Excluded tweets containing "H"
- Time visibility conditions

---

## ✅ Task 4 – Tweet Engagement Comparison

Compared:

- Replies
- Retweets
- Likes

Filters:

- Tweets posted between **June – August 2020**

---

## ✅ Task 5 – Monthly Engagement Trend

Line chart comparing:

- Tweets with Media
- Tweets without Media

Metric:

- Average Engagement Rate

---

## ✅ Task 6 – Top 10 Engaging Tweets

Ranked tweets using:

**Total Engagement = Likes + Retweets**

Applied filters:

- Weekdays only
- Even Impressions
- Odd Dates
- Word Count < 30
- Top 10 Tweets
- Visible Time
